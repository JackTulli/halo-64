# Optional campaign PC content: future design notes

This is original planning prose. Private offline reference review covered all ten missions; this public subset retains thirty future item decisions without reproducing the extracted reference. It does not include map files, placement tables, tag or palette records, script-object names, exact coordinates, textures, models or audio. None of these proposals establishes a built or playable campaign mission. Developers must supply their own permitted local inputs and verify each proposal against the actual mission before implementation.

All additions should be optional. Preserve the original item and vehicle lists, mission triggers, progression and checkpoints. Place new content through the existing scenario and object systems rather than a second spawn manager. Resolve locations from locally supplied mission data; keep extracted authored references in the private development workspace.

Every cell below is a future proposal or an explicit deferral. No landing location, clearance, pickup, route or checkpoint behavior has been accepted.

For each proposed placement, the eventual PR should explain its gameplay purpose, why the location is reachable, which native spawn and renewal behavior it uses, and how it preserves the original mission. Record source review separately from actual native pickup, driving, traversal, checkpoint, performance and device results. A clear location or collision probe alone is insufficient acceptance.

The detailed private reference remains available to its owner for local verification. It is intentionally not linked or reproduced in this public document.

Load a campaign level

  1. Make the level's data in Ubuntu, from the repository:
    python3 -m tools.n64.campaign_editor build/xbox/disc/maps/a30.map -o a30-level.json
  2. Load level… that file (or drop it here). Load an earlier edits file to go on with it.
  3. Drag items and squad points; Delete removes the selected one, Keep brings back one the converter left out. Shift-drag moves a whole squad. Add a squad puts a new one in the middle of the view: drag it where it goes, add points to it, set its counts.
  4. Save edits as campaign_edits/a30.json in the repository, then rebuild: ~/n64/tools/build.sh.
Drag empty ground to pan, wheel to zoom. Orange rings mark points high above the ground or under it.
